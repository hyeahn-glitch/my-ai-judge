# 🥗 다이어트 밀착 케어 시스템

마운자로 단약 후 **자력 유지 + 골격근 사수** 국면을 관리하기 위한 AI 케어 에이전트 운영 저장소.

## 현재 상태 (2026-09-10)

```
체중    83.3 kg ──────────────────▶ 62.6 kg ──▶ 🎯 59.9 kg
골격근  24.6 kg ──────────────────▶ 21.7 kg ──▶ 🎯 21.7 사수
체지방률  45.9 % ──────────────────▶ 35.2 % ──▶ 🎯 32 %
```

> **목표는 두 개다 — 체지방을 빼고, 근육을 지킨다.**
> 체지방률 35.2 %는 비만 범주이며 감량은 명확히 필요하다.
> 다만 **적자는 덜 먹어서가 아니라 더 움직여서 만든다.**
> 하루 **8,000보** + 근력 **주 3회** + 수면 **8시간(00:00 취침)**. (`INBODY.md`)

## 구조

```
diet/
├── README.md              ← 지금 이 문서 (진입점)
├── PROFILE.md             ← 프로필 · 투약 히스토리 · 영양 목표    [1순위]
├── INBODY.md              ← 체성분 실측 분석 (모든 추정치에 우선)  [2순위]
├── REBOUND.md             ← 단약 후 반등 분석 (체중 해석 시 필수)   [2순위]
├── PLAN.md                ← 58kg 로드맵 (14주 · 단계/주기 연동)     [2순위]
├── plan-58kg.html         ← 위 계획의 발행 문서 소스
├── PROTOCOL.md            ← 에이전트 행동 규칙 · 보고서 템플릿     [3순위]
├── TRAINING.md            ← 헬스장 근력 프로그램 (주 3회 · 상체 우선)
├── PRODUCTS.md            ← 라벨 실측 제품 DB (추정치보다 우선)
├── logs/
│   ├── _TEMPLATE.md       ← 하루 기록 양식
│   └── YYYY-MM-DD.md      ← 일별 식단 · 체중 · 활동 기록
└── data/
    ├── metrics.csv        ← 일별 정량 데이터
    └── inbody.csv         ← 인바디 측정 이력 (2025-09 ~ )
```

## 왜 파일로 관리하는가

알림 세션은 **매번 새로 시작된다.** 대화 맥락은 남지 않는다.
따라서 기억은 이 저장소에 있다. 모든 세션은
`PROFILE.md → INBODY.md → PROTOCOL.md → logs/오늘.md → metrics.csv` 순으로 읽고 시작하며,
임무를 마치면 **반드시 로그를 갱신하고 push** 한다.
